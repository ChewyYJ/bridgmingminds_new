# Pixel-art scenery

Downloaded 16 November 2026. The original PNG files are bundled locally, unchanged. The app applies a warm, low-saturation SVG colour filter at display time. No external image requests are needed while using the app.

| Local file | Work / creator | Source and licence |
| --- | --- | --- |
| `retropixelcity.png` | **Pixel City Background**, ZaninDevelopers | [Original artwork](https://opengameart.org/content/pixel-city-background), [PNG](https://opengameart.org/sites/default/files/retropixelcity.png). CC0. The creator describes photographing a miniature city and cleaning the resized image pixel by pixel in Piskel. |
| `sky.png`, `distant-city.png`, `middle-city.png`, `near-city.png` | **City Parallax pixel art**, GustavoSaraiva | [Original artwork](https://opengameart.org/content/city-parallax-pixel-art), [City.zip](https://opengameart.org/sites/default/files/City.zip). CC0. Extracted from `BG.png`, `Background 1.png`, `Middle.png`, and `Foreground.png` respectively. |

Both source pages identify their licence as [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). [Legal code](https://creativecommons.org/publicdomain/zero/1.0/legalcode.en).

`src/role3/PixelScene.tsx` combines those backgrounds with original SVG room, bookshop, civic-hall, paving and foliage shapes. The resulting neighbourhood is decorative and fictional; it does not depict a verified Singapore location. The previously approved avatar and food assets are separate from these scenery credits.

No image-generation service was used to create these replacement backgrounds.
